A 48-key hot-swap keyboard PCB for Micro Journal

This is the keyboard board used in Micro Journal Rev.2 Revamp, Rev.3, Rev.6 and Rev.6.1 Mini. Order a single board for a new build, a repair or an upgrade.

Why you will like it

  • No soldering for the switches. The hot-swap sockets accept Cherry MX compatible switches, so you can install or change switches at any time.
  • Made for Micro Journal. The 48-key layout and the pinout are designed for the Micro Journal firmware and mainboards, so it connects directly.
  • Order just one. Custom PCBs normally have to be ordered in bulk. I keep ready-to-ship stock with Elecrow, so one board is all you need.
  • Open source. Every file is public, from the manufacturing files to the schematic.

Good to know

  • Keyboard switches and keycaps are not included. Use any Cherry MX compatible switches you like.
  • Compatible with Micro Journal Rev.2 Revamp, Rev.3, Rev.6 and Rev.6.1 Mini.
  • It also fits the keyboard in the Micro Journal DIY kits, so you can use it to replace a board.
  • The board has connection holes for the microcontroller and for two EC11 rotary encoders.
