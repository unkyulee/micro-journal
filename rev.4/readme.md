# Rev.4: Keyboard That Becomes a Writing Device

Rev.4 is an ESP32-based keyboard. It is a regular mechanical keyboard for your computer, and it can instantly switch into a standalone writerDeck.

| Preview | Revision | Characteristics |
| ------- | -------- | --------------- |
| <img src="./4.0/images/001.webp" width="200"> | **[Rev.4](./4.0/readme.md)** | The original ESP32 build with an ILI9341 display and a hand-wired 30-key keyboard. It powers on immediately and syncs with Google Drive. Its firmware is shared by later revisions. |
| <img src="./4.0.revamp/images/014.jpg" width="200"> | **[Rev.4 Revamp: Captain Hook](./4.0.revamp/readme.md)** | A keyboard designed with writers in mind, with customizable keys, specialized characters (em dashes, smart quotes, accents) and mechanical switches. |
